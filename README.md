1. Project Overview

Broovy Compiler is the official compiler project for the Broovy programming language.

Broovy stands for:

Broovy Programming and Gradle Structured Broovy Language

The project is being developed to establish the foundations of a structured programming language and its compilation ecosystem.

The project includes the development of language specifications, compiler components, execution infrastructure, development tools, and technical documentation.

7. Language Architecture

The Broovy language architecture will define how source code is processed and executed.

The planned compiler architecture may contain the following components:

- Source Code Reader
- Lexical Analyzer
- Tokenizer
- Parser
- Syntax Analyzer
- Abstract Syntax Tree
- Semantic Analyzer
- Type Checker
- Intermediate Representation
- Code Generator
- Compiler Backend
- Runtime Environment

These components represent the intended architecture and are not necessarily implemented yet.

8. Compiler

The Broovy Compiler is the central component responsible for processing Broovy source code.

Its planned responsibilities include:

- Reading source files.
- Identifying language tokens.
- Analyzing syntax.
- Checking semantic rules.
- Reporting compilation errors.
- Generating executable output.
- Supporting compiler diagnostics.

11. Compiler Components

The compiler architecture is expected to include several independent components.

11.1 Lexer

Responsible for identifying tokens in source code.

11.2 Parser

Responsible for analyzing the grammatical structure of source code.

11.3 Semantic Analyzer

Responsible for checking semantic correctness.

11.4 Type Checker

Responsible for validating type compatibility.

11.5 Intermediate Representation

Responsible for representing programs internally.

11.6 Code Generator

Responsible for generating output from the compiler representation.

11.7 Diagnostics

Responsible for reporting errors, warnings, and informational messages.
